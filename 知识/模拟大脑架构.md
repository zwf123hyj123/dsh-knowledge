# 模拟大脑 · 架构（自主执行模块之一）

> 基础思想参考：Anthropic《The components of agent memory》（四层记忆 + Dreaming 回查纠错）。
> 一句话定义：**记忆 = 自己已有的知识；有用的知识转为记忆；突触 = 关联；思维碰撞 = 自动关联 + 反幻门。**

## 分层

| 层 | 实体 | 职责 |
|---|---|---|
| 记忆层（自有知识） | 原话库 / 记忆笔记 / 连续性卡 / 会话卡 / 发布清单 | 已知事实与语气，最高权威 |
| 知识层（外部知识） | BRAIN_ROOT/知识/*.md（全网搜索结果落盘，带出处） | 可检索知识；本地存目录，git 版本控制 |
| 突触层（关联） | BRAIN_ROOT/突触/synapses.jsonl | 实体↔实体↔关系的关联索引 |
| 工具层 | 压缩 CLI / 防炸监控 / 保活 / 检索工具 | 执行手段 |
| 思维碰撞 | brain/思维碰撞.py | 自动关联引擎：扫描 → 候选突触 → 反幻门 → 输出建议 |

## 思维碰撞机制

1. 扫描记忆层+知识层的关键词共现。
2. 生成候选突触 {实体A, 关键词, 共现, 来源, 频次}。
3. **反幻门**：项目名/实体名先过 发布清单.md 白名单；清单外且像项目名 → 只进「待核实」，不建突触；原始记录不改、勘误覆盖。
4. 输出候选建议 + 待核实名单，人机确认后转正。

## 知识生命周期（反幻配套）

- 全网搜索的资料 → 落 知识/日期-主题.md（必带出处链接）。
- 项目用完后自动关联：任务完成时该项目知识条目打 done，并与项目名建突触归档。
- 有用的知识 → 提炼为记忆笔记，形成「知识→记忆」转化通道。

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| BRAIN_ROOT | ~/.dsh/brain | 知识/突触/发布清单根目录 |
| DSH_HOME | ~/.dsh | 引擎家目录（lazarus 工具与 sessions） |
| INBOX_SID | 空 | 收件箱归档的会话 id（前 13 位） |
| CTXC_BIN / BRAIN_BIN | 空 | 防炸监控要调用的压缩/碰撞脚本路径（不配则跳过） |
