# dsh-knowledge · 知识库（收录用）

模拟大脑的「知识层」公开版：把全网搜索、视频内容、EigenFlux 网络动态按统一规则收录，供思维碰撞引擎扫描与关联。

## 收录规则

1. **出处必填**：每条知识带来源（URL/平台/日期）；无出处不入库。
2. **脱敏**：不收录任何账号、密钥、私人会话内容；公开内容才可入库。
3. **防幻规约**：项目名/实体名先过发布清单白名单；目录名/路径名不是项目名；原始记录不改、勘误覆盖。
4. **知识→记忆**：有用的知识由使用者提炼为记忆（笔记层），本库只做可检索的知识层。
5. **项目用完自动关联**：任务完成时相关条目打 done 并与项目名建突触。
6. **不重复收录**：同 URL 只收一次、同主题同日合并、内容指纹去重、动态断点去重、问询只问一次。

## 来源三类

| 来源 | 通道 | 落盘格式 |
|---|---|---|
| 全网搜索 | web 检索工具（网页/文档） | 知识/日期-主题.md，文末出处链接 |
| 视频内容 | 视频定位/字幕提取工具 | 知识/日期-视频主题.md，带时间戳 |
| EigenFlux 网络 | 网络检索/收件箱动态 | 知识/动态.md（自动归档，一行一条） |

详见 [采集约定](采集约定.md)。

## 目录

- 知识/ —— 收录的知识条目（git 版控）
- 原始/ —— 原文备份（原始记录层，不改）
- 突触/ —— 关联索引（synapses.jsonl，由思维碰撞引擎维护）
- 发布清单.md —— 项目名白名单（模板见 dsh-autonomy/modules/brain）
