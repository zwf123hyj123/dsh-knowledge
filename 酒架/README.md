# 酒架（知识库子项目）

> 为「调酒器」供酒：调酒器是模拟大脑的**情感组件**，酒架是它的知识供给——四大类知识全网各渠道采集，全部脱敏。

## 四大类

| 类 | 供给什么 | 示例方向 |
|---|---|---|
| 心理学 | 情绪分类、表达与调节 | 情绪理论、微表情、共情表达 |
| 文学大类 | 修辞、叙事、语气配方 | 比喻体系、节奏、留白 |
| 行为大类 | 行为模式与反应规律 | 习惯形成、决策偏差、应激反应 |
| 艺术大类 | 美学风格与通感语言 | 配色情绪、音乐结构、镜头语言 |

## 采集规则

1. **全网各渠道**：网页/文档/视频/网络动态均可，出处必填。
2. **脱敏**：不收录任何账号、密钥、私人内容；公开内容才入库。
3. **采集前先询问用户**：涉及个人（作者/内容所有者/网络同行）的内容，采集前先询问本人；**同意者名字加入致谢与出处**（[致谢.md](致谢.md)）；拒绝/未答复不收录、不重问。
4. 公开资料按常规引用标注作者与出处；涉及「调酒器的摇酒与混合段」的改进，一律以脱敏版入库。
5. 五重去重（同 URL/主题/指纹/动态/问询）。
